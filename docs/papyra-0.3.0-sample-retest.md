## 内容与离线

- 从三份 Markdown 提取标题、元信息、段落、列表、表格单元格与代码，共 274 块。移除增强 DOM 后逐块、按原序比较，普通文字忽略排版空白，代码保留内容与内部空白（仅忽略结尾换行）。元信息允许位于图签中，单独按原文核对。
- 补齐了图签、图注、装饰符号、推荐徽章等增强节点的可剔除属性。原文标题与元信息不再被增强父节点连带删除。
- 三份输入 Markdown 的 SHA256 前后一致。
- 输出逐份包含与 Skill 完全一致的库、CSS 和初始化脚本；没有外部 script/stylesheet，HTTP/HTTPS 请求 0，页面异常及 error 控制台消息 0。
- 每份单独复制至临时目录后，在断网 Chrome 中仍可打开并绘制标注。禁用脚本后原文及普通 CSS 强调保留。

## 浏览器与交互

使用本机 headless Chrome、独立临时 profile 和 `file://`，无需 npm 依赖。每例检查 9 个布局状态，共 27 个；另有真实鼠标/键盘输入的交互断言。

- 1440px 桌面、390px、320px 无整页横向溢出；宽表格可以局部横向滚动。
- 720 CSS px + 2 倍像素密度模拟 1440px 的 200% 缩放重排；不等同于操作 Chrome 缩放菜单。
- 所有标注均有路径、增强属性及装饰语义；跨行、纯位置变化、自定义刷新、隐藏再展开、圈选跨行降级与主题变量更新后几何位置正确，无重复 SVG。
- 每例实际高亮文字与背景对比度不低于 4.5:1；需求页使用深色主题，另两例使用各自浅色主题。
- 运营页目录点击后到达风险章节。
- 需求页五个状态点选显示正确后续状态，Enter 可激活；代码复制的成功与失败反馈均验证。复制使用测试适配器，不代表真实系统剪贴板权限已通过。
- 设计页分区点击后定位并聚焦表格行，高亮保持；手机目录默认收起，原生 Enter 可切换；桌面与手机断点变化时目录同步。
- 已目检三例桌面首页、390px 首页、320px 正文深处及标注画面。

## 打印

在关闭打印背景的条件下生成 4/4/6 页 PDF。验证所有原文块（含标题和元信息）在打印布局中可见；隐藏手绘 SVG，用普通下划线保留重点，避免深色高亮文字在白纸上消失。运营页进度条与预算条要求精确打印颜色，背景选项关闭时仍可辨识。

用 macOS PDFKit 提取文字，核对标题、元信息或预算及末尾关键原文，并查看三例 PDF 首页和代表性正文页。未逐页认证每个图形和全文 PDF 阅读顺序，不把这些辅助检查等同于完整打印认证。

## 本轮修复

1. 运营页 IntersectionObserver 的 rootMargin 从非法 rem 改为计算后的 px。
2. 设计页目录增加断点监听，不再只在首次加载时决定展开状态。
3. 设计页焦点高亮不再被随后的 mouseleave 清掉。
4. 需求页状态与复制反馈更新布局后调用统一标注刷新入口。
5. 需求页打印保留原文标题和元信息；通用标注 CSS 打印时继承正文颜色，关闭高亮背景；运营页打印保留数据条填充。
