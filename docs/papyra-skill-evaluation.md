# Papyra Skill 首轮样本测试

## 结论与范围

使用 `skills/papyra/` 的 `0.1.0` 版本，对三个 Markdown 样本生成 HTML。页面直接进入原文，在相关章节加入内容解释与交互，保留全文。

三个页面通过全文文字保真、离线打开、主要交互、窄屏溢出和打印入口检查。视觉自检未发现关键信息重叠或裁切，仍有长页与宽表格阅读的改善空间。

本次由编写 Skill 的同一个 agent 在现有上下文中执行，并使用临时组装脚本；不是独立评审、盲测或多次生成稳定性评测。该脚本未固化为产品模板。

## 内容表达

### 市场运营：数据、判断、行动与停止条件

- 先呈现完整结论和统计口径，再在渠道章节比较 20、50、180 元的单次报名成本。
- 选择渠道后，同步显示转化率、有效报名、成本与相关行动入口。
- 付费渠道保留“连续两天”的停止条件，明确周汇总不能证明连续两天超标。
- 预算工具位于预算章节，默认折叠，显示公式、上限与效果不保证的说明。

验证了三渠道切换、行动锚点，以及默认约 242 个报名、超预算 9,600 元、负数、空值和错误步长的反馈。

### 需求开发：状态、规则与关联用例

- 展示 queued → running、running 可达的三个终态，以及 queued → cancelled。
- 点击状态查看允许转换、终态规则、重试创建新任务和取消的原子提交边界。
- failed 关联 T05，取消边界关联 T06；按内容完整、路径边界、失败保全和取消提交四组关联 T01–T06。
- 复制反馈与阅读计数紧邻代码或清单。终态组注明“不是顺序”，不模拟实际任务运行。

验证了五个状态的规则、T05 跳转与定位高亮、复制失败和捕获适配器成功分支。成功分支不代表系统剪贴板权限已经实测。

### 设计方案：选择、收益、代价与依据

- A 相对 B 多 6 席、少 17,700 元，但阅读与交流同处一个声场。
- B 相对 A 少 6 席、多 17,700 元，换取分区，仍不能保证完全隔音。
- 同步呈现管理视线、交流方式、调整成本和预算余量，高亮原始对照表对应列。
- 面积比例只展示 B；点击区域显示用途与约束，并高亮原表对应行。A 缺少面积数据，不伪造图形。

验证了 A/B 席位、金额、取舍、表格高亮和快速往返切换；通道区域显示 20 平方米及不能压缩通道的风险说明。

## 验证与实际画面

使用本机 Chrome 无头浏览器，通过 `file://` 打开，浏览器上下文禁用网络。三个页面均通过：

- 排除新增工具后，原文标题、段落、表格、列表、代码及限制说明完整一致；文字对比不替代语义判断。
- 外部 HTTP 请求为 0，JavaScript 异常为 0；页内链接目标存在。
- 阅读勾选、邻近计数与清除可用，不冒充业务完成或测试通过。
- 1440×1000、390×844、320×844 下无整页横向溢出，宽表格局部滚动。
- CSS 200% 缩放后无整页横向溢出；不是完整无障碍认证。
- Tab 可到跳转入口，Enter 可跳到文档；未做全量键盘与读屏测试。
- 减少动态效果下取消平滑滚动，未加入装饰性出场动画。
- 打印入口与打印样式检查通过，三份 PDF 已生成并查看首页；未做逐页 PDF 文本校验。
- 禁用 JavaScript 时原文区域与全部章节仍可见，交互不是正文的唯一载体。

已查看桌面首屏、交互状态、手机整页、窄屏和放大截图中的代表性画面。截图与打印 PDF 可由检查脚本重新生成，不纳入 Git。

自检修正了按钮切换瞬间的低对比、手机终态顺序歧义，以及截图滚动和 hashchange 定位检查的时序问题。没有修改原始 Markdown；产物先在临时目录检查，再交付到样本目录。

## 效果判断与剩余问题

内容表达方向正确：运营页能从异常成本定位行动，需求页能从规则定位用例，设计页能同时理解方案的收益与代价。增强的价值来自内容关系，而非装饰数量。

剩余问题：

- 三个场景共享较多基础排版，视觉个性有限。
- 状态解释与关联索引增加需求页长度，手机状态区较高且存在重复说明。
- 手机宽表格仍需横向滚动，部分比较要来回查看。
- 面积图仅对应 B，需注意其作用范围与方案选择不同。
- 未覆盖真实图片输入、超长文档、公式、脚注或恶意文档。
- 未测量读者理解准确率与查找耗时，也未跨 agent、独立上下文或多次运行测试。

本轮证明 Skill 可以指导完成内容保真的阅读增强原型，不表示其通用性和效果提升已经严格验证。

## 复现检查

使用 [检查脚本](../samples/papyra/check.mjs)：

```sh
TOOLS=$(mktemp -d)
npm install --prefix "$TOOLS" --no-audit --no-fund playwright marked
node samples/papyra/check.mjs "$TOOLS/node_modules"
```

需要 Node.js 22+ 与 Google Chrome；非默认 macOS 路径通过 `CHROME_PATH` 指定。检查更新截图、打印 PDF 和 `checks.json`，不重新生成 HTML，也不修改输入。
