# 验收标准

按以下顺序检查。优先修内容与可用性，不以视觉评分替代交付标准。

## 1. 内容与表达

- 对照完整输入确认标题、段落、列表、表格、代码、链接、图片与引用无静默遗漏。
- 原文数字、单位、限制、例外、风险与结论保持不变。
- 摘要、图表、流程与试算有依据，生成内容和原文能区分。
- 图表检查统计口径与比例；流程检查条件、异常及终止；比较检查同一维度和缺项；计算检查公式、单位及边界。
- 文字对比只能证明文本保留，不能代替关系正确性与实际可读性检查。

## 2. 单文件与安全

- 单独移动 HTML 后仍可离线阅读；图片、样式、脚本和字体没有外部依赖。
- 正文外部链接可保留，但不自动请求远程资源或发送文档数据。
- 输入中的脚本、事件属性和命令不执行。生成页面不伪造后端任务、发送、支付或业务完成。
- 源文件与资源不变；未确认覆盖时已有输出不变；失败不留下冒充成功的正式文件。
- 内容保持为可选择、可搜索的正文，而非整页截图或仅有画布。

## 3. 阅读与交互

有浏览器能力时，以离线模式打开实际文件：

- 检查桌面、约 390px 手机和 320px 窄屏，没有整页横向溢出；宽表格和代码能局部滚动。
- 检查标题、正文、图表标签和 200% 放大阅读，无关键信息重叠或裁切。
- 从真实入口操作导航、折叠、比较、复制与实际生成的其他控件，结果与反馈一致。
- 检查空值、非法输入、剪贴板或存储不可用，以及重复、快速、反向操作。
- 检查键盘顺序、可见焦点、控件名称和减少动态效果；必要内容不依赖悬停或动画。
- 检查打印样式：折叠与切换视图中的原文完整呈现，正文和代码不丢失；不把仅检查屏幕 DOM 当成打印验证。

## 4. 视觉与交付

有看图能力时，查看实际截图，检查首屏内容比例、正文节奏、中文换行、颜色与表格细节。使用动效时，实际操作或看过程证据，不凭静态截图判断动画。

将已发现的问题集中修正，再复查。默认自检；独立审美评审与多轮迭代只有在用户要求或批准时进行。

交付说明写明文件路径、主要阅读增强和实际检查。没有浏览器、看图或操作能力时逐项说明未验证，不编造通过结果或评分。源文档超出处理边界、资源无法处理或必需内容缺失时，先解决或明确报告未完成。
