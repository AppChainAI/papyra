# 文档导出任务：需求与验收规格

版本：0.3。负责人：沈禾。计划评审：2026 年 10 月 6 日。

## 问题与目标

用户需要把一份 Markdown 文档导出成可离线阅读的 HTML。当前人工复制内容会丢失图片与代码格式，也无法确定生成过程中是否遗漏章节。

本期交付单文档导出：保留内容、明确进度、失败可重试，且不覆盖已有有效文件。本文是需求规格，不表示功能已实现。

## 用户故事

作为项目负责人，我希望把需求文档导出为一个 HTML 文件，发给没有开发环境的同事；对方断网后仍能阅读正文、图片与代码。

## 范围

### 本期包含

- Markdown 文件与同目录中的关联图片。
- 单个 HTML 输出，内嵌样式、脚本和必要图片。
- 任务状态查询、失败原因展示和手动重试。
- 同名文件冲突确认与临时文件原子替换。

### 本期不包含

- PDF、扫描件 OCR 与批量导出。
- 多用户协同、在线发布与远程图片下载。
- 自动修改原文、翻译正文或事实补全。

## 状态与约束

| 状态 | 含义 | 允许的后续状态 |
| --- | --- | --- |
| queued | 已接收，尚未执行 | running、cancelled |
| running | 正在生成与校验 | succeeded、failed、cancelled |
| succeeded | 校验通过并交付文件 | 无 |
| failed | 生成或校验失败 | 无；重试创建新任务 |
| cancelled | 用户取消，未交付文件 | 无 |

取消与成功同时发生时，以服务端完成交付的原子提交点为准。成功提交之前收到取消，不得交付；提交之后取消返回“任务已完成”。

## 接口草案

以下接口用于评审，不是当前可用 API。

```http
POST /api/exports
Content-Type: application/json

{
  "source": "docs/spec.md",
  "output": "exports/spec.html",
  "overwrite": false
}
```

接收成功返回 `202 Accepted`：

```json
{
  "id": "exp_7f32",
  "state": "queued"
}
```

错误边界：

- `400`：路径或参数不合法。
- `404`：源文件不存在。
- `409`：目标文件已存在，且未确认覆盖。
- `422`：图片缺失或文档超出支持边界。
- `503`：生成 agent 不可用。

相对路径以工作区根目录解析。拒绝路径穿越及通过符号链接逃逸工作区；不能仅检查字符串前缀。

## 验收清单

- [ ] 断网打开 HTML，正文、图片和必要交互正常。
- [ ] 标题、段落、表格、代码与链接没有静默遗漏。
- [ ] 源文件及图片的内容哈希不变。
- [ ] 未确认覆盖时，原有输出文件保持不变。
- [ ] agent 失败后清理临时文件，保留已有有效产物。
- [ ] 取消任务不会留下冒充成功的半成品。
- [ ] 路径穿越与符号链接逃逸被拒绝。
- [ ] 390 像素宽度与键盘操作下可以阅读和使用。

## 测试用例

| 编号 | 输入或操作 | 预期结果 |
| --- | --- | --- |
| T01 | 包含中文标题、表格与代码的 Markdown | 内容完整，排版可读 |
| T02 | 图片路径为 `./assets/flow.png` | 图片内嵌，离线显示 |
| T03 | 输出文件已存在且 overwrite=false | 返回 409，原文件不变 |
| T04 | 源路径为 `../private.md` | 拒绝访问，不读取文件 |
| T05 | agent 生成中崩溃 | 状态 failed，保留原有有效文件 |
| T06 | 原子提交前取消 | 状态 cancelled，不交付输出 |

## 发布门槛

T01–T06 全部通过后才能发布。禁止以“HTML 文件已生成”替代验收，也不得将界面里的本地勾选视为真实测试执行结果。

## 未决事项

1. 最大文档长度与单张图片大小需要用真实样本测量后确定。
2. agent 超时时间及中断方式由首次集成结果决定。
3. 接口错误码属于草案，客户端与服务端需在实现前共同确认。
